JAIVEERCPP — C++ DSA ARRAY TRACKER

1. Extract the folder.
2. Double-click Start_JaiveerCPP.bat.
3. Browser app opens automatically.
4. Click "Open in VS Code" on any question.
5. That question's .cpp file opens directly in VS Code.
6. Green completion ticks are saved in the browser.

Keep the black PowerShell window open while using the app.

If "Open in VS Code" says VS Code CLI was not found:
- Open VS Code.
- Press Ctrl+Shift+P.
- Search: "Shell Command: Install 'code' command in PATH" if that command is available.
- Restart JaiveerCPP.

The app is local and does not need internet.
